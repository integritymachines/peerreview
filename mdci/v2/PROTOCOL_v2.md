# Frozen pilot v2 protocol

Date: 2026-11-06. Source repository main revision: 898e0dbde9a0ba1cd160cdcec0a66336d2abce72. The main README and the prior local pilot/REPORT.md were read before preparation. The previous run tested design compatibility and is a failed operationalization of framework choice; its output is not training data or adverse evidence about MDCI.

## Target and selection

Assess frameworks, not IV/DiD/RD/matching/weighting/other designs. Candidate vocabulary: Rubin/Neyman potential outcomes; Pearl structural causal models; Heckman/Haavelmo structural econometrics; mechanistic dynamical causal models; named other frameworks. Hybrids contain explicit components. Frameworks overlap and can translate some common causal assumptions; a unique winner is not required.

Twelve empirical published applications are purposively selected for different prior structures and counterfactual demands, with at least 300 indexed citations per final journal article using a transparent bibliometric source. Counts are database-specific, not a common ranking. Selection slots cover socially opaque labor-market responses, rule-mediated schooling and wage constraints, behavioral replacement and market/policy responses, longitudinal treatment/health dependence, perturbed intracellular signals, inherited genotype/lipid/disease relations, physical weather and mediated economic output, epidemic transmission and policies, and parasite transmission with school allocation and spillovers. Selection is not based on known review failures or published criticism. Canonical source versions, counts, access changes, and reasons are recorded in selection.json and preparation metadata.

Pre-assessment changes: illustrative general MSM paper replaced by its observed HIV cohort application; hypothetical influenza simulation replaced by observed epidemic inference; inaccessible Keane–Wolpin final paper replaced by a final published unemployment-insurance application preserving behavioral/policy scope. These are empirical-scope/access changes before any assessments, not result-based exclusions. No preprints substitute for final articles. Missing separately published supplements remain documented, rather than silently treated as read.

## Inputs, measurement and locked interpretation

Independent preparers produce 350–550-word retrospective ex-ante-content dossiers from original domain/data descriptions. They remove author/framework/design labels, identifying equations, conclusions, empirical effect estimates and diagnostics. Physical/institutional procedures remain facts; unsupported mechanisms remain assumptions. Parent edits before freezing distinguish arithmetic/accounting/legal constraints from physical necessity and preserve the actual school-allocation procedure rather than adopting a methodological label. The metadata preserves these edits. Neither dossiers nor published apparatus are ground truth about unobserved mechanisms.

Freeze dossiers, full article texts, PDFs, manifest, prompts, source metadata and protocol with SHA-256 before assessment. A and B receive byte-identical dossiers. A uses R/F/D evidence scores with a common 0, .25, .50, .75, 1 scale; D requires domain-specific physical direction beyond chronology. The scores are evidence strengths, not probabilities or proportions. Three preselected cases q02/q05/q08 receive a second independent A assessment to assess measurement consistency. Three repeats estimate within-host prompt repeatability only, not external inter-rater validity.

No validated signature-to-framework lookup exists in the supplied module. This run explicitly tests the frozen prompted operationalization: use the signature to check each framework's ability to express the target and respect the warranted restrictions without unsupported assumptions. Relational opacity does not uniquely require potential outcomes; functional restrictions do not uniquely require structural econometrics; physical constraints do not disqualify potential outcomes or uniquely imply a dynamical framework. A claimed material preference requires a stated advantage and assumptions. This missing independently calibrated mapping is a substantive measurement limit to be evaluated, not an invitation to invent a taxonomy rule.

## Independent branches and inference budget

Use fresh-context host agents with no inherited parent history; never reuse a preparation worker for assessment. A sees only A prompt and dossiers; B sees only its neutral framework prompt and the SAME dossiers, with no MDCI/R/F/D/cube terminology or results; baseline sees only domain and estimand and the common framework vocabulary. C is a separate context receiving full published article text/PDF and available supplements, with no dossiers, A/B/baseline findings or experiment hypothesis. C extracts actual formal apparatus and records designs separately. Generic regression, familiar citations or estimator names do not establish school membership. Underidentified membership and compatible hybrids are legitimate outputs.

Minimize overhead by batching cases within a branch; batches use mixed domains. This preserves cross-branch information separation, but permits within-batch context and shares a model lineage, so errors need not be statistically independent. Use one concise assessment per paper per branch, one independent repeat for q02/q05/q08 only, no model sweeps. There are 12 A + 12 B + 12 baseline + 12 C + 3 repeat case assessments. Host inference calls/agent turns need not equal that count; token/cost telemetry and exact inherited model ID are not exposed. Do not claim a free run or an API model that was not used.

A/B/baseline/repeats must all be frozen and sealed before ANY C worker is launched. No substantive A/B inspection before the seal. C source acquisition occurs earlier for dossier construction, but C framework extraction does not. Preserve request/response hashes, launch assignments and deviations. Freeze all C outputs before final comparison. Host permissions are procedural, not separate filesystem sandboxes. The original review.txt is never run or modified. All new/modified workspace files remain under mdci/.

## Comparison and decision criteria

Primary descriptive endpoints: A/B suitable-set equality, intersection, Jaccard, preferred-set agreement, preference status, candidate-set size and abstentions. Compare domain-only baseline against B using identical metrics and report paired A-minus-baseline Jaccard differences. B is also the same-information/no-signature comparison: any apparent improvement over the narrower baseline can reflect richer inputs rather than the R/F/D classification. Do not infer marginal information in R/F/D merely from A/base differences. No significance testing or population accuracy estimate is justified.

Compare C only after the A/B seal. Distinguish full framework agreement; partial agreement or an explicitly compatible hybrid; equally admissible alternatives; materially demonstrated framework mismatch; and indeterminate membership/suitability. C-framework coverage by a candidate set is descriptive admissibility, not proof of fit. Neither a difference of school label nor a different design establishes mismatch. An actual mismatch requires located apparatus conflicting with warranted restrictions or a materially superior same-evidence framework with stated credible assumptions. If this cannot be demonstrated, retain alternatives/indeterminate rather than manufacture a verdict. Full agreement can coexist with multiple equally admissible alternatives; report these dimensions separately.

Repeat A measurements: absolute coordinate differences, mean/max differences, candidate-set Jaccard/equality, and preference stability. No post-hoc change to scoring, framework labels, dossiers or primary metric denominators. Automated validation errors may be corrected only if syntactic, documented, and not a substantive reassessment; preserve original outputs. Exact C quotes are short (20 words total per paper) and audited against supplied full text with whitespace/OCR normalization; located equation descriptions are checked separately where possible. This audit is provenance, not replication.

The vocabulary is an operational representation, not an endorsement of one author's claim that a framework subsumes another. Framework capability and empirical support for a model must be separated.
