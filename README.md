# peerreview

Two possible workflows:
- review.txt -> preview.txt produces a pre-submission self-text. No verdict is offered (it defaults to "revise"), but recommendations for improvement are offered both by relevance and chronologically.
- review.txt -> report.txt produces a review report for a submitted paper at a top journal. The report offers a verdict plus an itemized list of flagged concerns.

The processes are written to provide a pinpoint-accurate, unbiased, cordial assessment of the submitted paper given the embedded criteria. The end product of the review prompt is an itemized scorecard, which can be published or remain hidden. The current set of criteria is set up for economics, but it can be expanded or swapped out for other fields, while keeping the workflow intact. 

It is recommended that this process is run in conjunction with a freeform review. It should augment but not replace human effort. In all cases, no warranties are offered or implied. Ultimate responsibility rests with the human operator.
